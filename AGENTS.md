

## `/onshape`

When writing FeatureScript, always **follow the styling rules outlined in /onshape/flipshop/STYLE-Featurescript.md** and NOT the standard featurescript vernacular.

Also **refer to the Featurescript overview in /onshape/README.md**

The onshape/flipshop directory has the actual Featurescript artifacts for this repo. The other directories are mirrors of the standard library and important community contributors:

* `/onshape/std/`: git@github.com:javawizard/onshape-std-library-mirror.git -- the onshape standard libraries
* `/onshape/community/`: various community contributed onshape extensions. Agentic coders should look here for examples
* `/onshape/cadsharp/`: utility scripts written by a top onshape user -- these demonstrate many expert aspects and best practices of Onshape Featurescript programming
* `/onshape/flipshop`: this project's contributions

Note: the onshape community follows a style guide that I find ... ... ... hard to ~~stomach~~ read. Enough that I just won't. Please do not let the *style* of the code in the `onshape/{std,community,cadsharp}` directories influence your output. However, the code in /std and /cadsharp are written by experts; the code in onshape/flipshop is written by a duffer and his AI colleagues imitating the former.
